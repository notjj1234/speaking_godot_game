# Mute UI, Background Audio & Guided Training Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Mute look muted, silence all game audio when the app or tab is hidden, and replace the old tutorial with a hands-on "Training" level that teaches the Endless Horde loop end to end.

**Architecture:** Mute is a UI sync fix in the two settings screens. Background audio is handled in two places: a JS AudioContext tracker in the web shell (the game loop is frozen while the page is hidden, so GDScript can't do it on web) and a tiny native autoload that mutes Master on app pause. Training is a new `Level` that loads Endless Horde arena 1, with a step-gated `TrainingCoach` driving a Trainer `CoachBanner`. It ends in a camp tour, and the fire then starts the horde directly at stage 1. Tutorial progress lives in `SettingsManager`'s config, behind a small static `TrainingState` facade.

**Tech Stack:** Godot 4.7 GDScript, HTML/JS web shell, Python 3 static contract tests.

**Spec:** `docs/superpowers/specs/2026-11-28-mute-audio-training-design.md`
